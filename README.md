## Diagnóstico de Hábitos de Consumo

Aplicação web interativa desenvolvida durante a Jornada Liga STEAM com foco em sustentabilidade e experiência do usuário. O projeto simula um diagnóstico de hábitos de consumo consciente por meio de um quiz dinâmico, oferecendo feedback personalizado com base nas respostas do usuário.

Desenvolvido com HTML, CSS e JavaScript, o projeto utiliza manipulação do DOM, interatividade da interface e armazenamento local de dados com LocalStorage, permitindo salvar a última pontuação diretamente no navegador.
